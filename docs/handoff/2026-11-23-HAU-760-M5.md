## Design changes from the plan (plan updated)

1. A device's Drive files hold only the records it pushed, kept in memory by the transport, not "every synced row"
   read from the database. The transport needs no database access and `_sync_rows.in_delta` was dropped.
2. File names carry the app: `<app>.<deviceId>.base.json`.
3. When the cursor's own base is gone, pull answers `reset`, so the device re-pushes everything.
4. Kotlin returns the token only; account id and email come from Drive's `about`. Sign-out passes the email to
   `revokeAccessAsync` because `RevokeAccessRequest` needs the `Account`.
